git基本代码

提交

克隆远程仓库，仅拉取 dev 分支代码与提交记录，不获取其它分支（main、test、release…），本地切换不到其他远程分支

小坑提醒
👉 -b dev 只是「默认检出 dev」，依然会下载所有分支；
想要只拉单个分支，必须搭配 –single-branch

更新分支

vscode看不到新建的远程分支
在项目文件打开git运行命令：git remote update origin –prune

git remote update 远程仓库名字–prune

未提交文件回退

✅ 已有历史提交（本地 + 远程都有）
✅ 本次只是工作区修改，还没 add /commit
✅ 目标：保留分支，删掉本次所有改动，回到上一次代码状态
