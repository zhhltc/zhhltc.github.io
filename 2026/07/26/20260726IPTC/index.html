注意

macOS 与 Windows 系统差异 & 重要注意事项

  1. 系统差异
    ① 可执行程序名称
    Mac：直接调用 exiftool
    Windows：环境变量配置完成可写 exiftool；未配置环境变量必须写 exiftool.exe
    ② 文件路径分隔符
    Mac：/
    示例：”/Users/xxx/AmazonVideo/demo.mp4”
    Windows：
    CMD：推荐 \；PowerShell：/ 和 \ 均可
    示例：”D:\AmazonVideo\demo.mp4”
    路径包含空格必须包裹英文双引号 “路径”，两端规则统一。

通用高危注意事项
视频编码顺序硬性规则
必须：视频导出最终 MP4 → ExifTool 写入元数据；
禁止：先打标签，再使用剪映 / FFmpeg/AME 二次转码，转码工具会丢弃 XMP 元数据。
容器格式兼容
✅ 稳定支持：MP4、MOV
⚠️ MKV：XMP 写入兼容性差，电商平台大概率无法识别
❌ WebM、AVI：不建议嵌入 XMP 用于亚马逊合规场景
校验标准
剪映、播放器、媒体预览工具无法可靠读取视频内嵌 XMP，唯一校验方式：exiftool 查询命令
字符引号规范
全部使用英文双引号包裹文本内容；Windows CMD 对单引号支持存在缺陷，不要混用单引号。

元数据字段参考

XMP元数据字段完整对照表

说明：

  1. 字段前缀 XMP- 为ExifTool调用格式；
  2. PNG、MP4视频仅支持XMP字段，不支持老式IPTC-IIM；
  3. dc:Subject 为数组Bag类型，使用 += 追加；其余大多为单文本；
  4. 区分两套容易混淆地点字段：photoshop:*（PS私有） vs Iptc4xmpCore:*（标准跨软件，推荐优先使用）

1. Dublin Core（dc 命名空间｜核心基础字段）

UI展示名称 ExifTool完整指令字段 命名空间 数据类型 业务备注
Title XMP-dc:Title dc 单文本 素材标题
Description XMP-dc:Description dc 单文本 素材描述
Creator XMP-dc:Creator dc 单文本 创作者
Source XMP-dc:Source dc 单文本 素材来源链接/来源说明
Subject XMP-dc:Subject dc Bag数组 ✅亚马逊合规标签 contains-synthetic-performer 存放位置
Rights XMP-dc:Rights dc 单文本 版权文字声明

2. IPTC4XMP Core（标准IPTC XMP，推荐优先使用）

UI展示名称 ExifTool完整指令字段 命名空间 数据类型 业务备注
Rights Usage Terms XMP-Iptc4xmpCore:RightsUsageTerms Iptc4xmpCore 单文本 使用权限说明
City XMP-Iptc4xmpCore:City Iptc4xmpCore 单文本 城市
State/Province XMP-Iptc4xmpCore:ProvinceState Iptc4xmpCore 单文本 省/州
Country XMP-Iptc4xmpCore:Country Iptc4xmpCore 单文本 国家名称
Country Code XMP-Iptc4xmpCore:CountryCode Iptc4xmpCore 单文本 ISO两位国家代码（CN/US等）
Sublocation XMP-Iptc4xmpCore:Sublocation Iptc4xmpCore 单文本 细分地点
Intellectual Genre XMP-Iptc4xmpCore:IntellectualGenre Iptc4xmpCore 单文本 作品类型
Headline XMP-Iptc4xmpCore:Headline Iptc4xmpCore 单文本 新闻/素材标题摘要

注意

WebP：新版 ExifTool 才完整支持 WebP 写入 XMP，建议升级 ExifTool 到最新版
视频兼容性重点
MP4、MOV 原生支持内嵌 XMP；
MKV、WebM 绝大多数不能内嵌 XMP，exiftool 默认会生成 .xmp 附属文件，不会修改视频本体；
如果不想生成 sidecar 文件，无法对这类容器写入内置元数据，属于格式限制。
-overwrite_original 会自动生成 _original 备份原文件，方便出错恢复；不需要备份可以移除该参数。
Windows：下载 ExifTool，解压后把 exiftool.exe 放到系统 PATH，或者和 bat 脚本放在同一文件夹。

参数说明
-s3：仅输出纯文件路径，无多余文字，txt 干净整洁
-if ‘not $XMP-dc:Subject =~ /关键词/‘ 正则匹配筛选
清单生成在目标文件夹 AddIPTC 内
如果 txt 是空文件 = 所有文件都成功打上标签
⚠️重要提醒（视频）
MKV / WebM 无法内嵌 XMP，只能生成附属 xmp 文件；
这类文件执行写入后，本体元数据不会变化，校验脚本会判定为缺失标签，属于格式限制。
